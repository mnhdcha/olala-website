# OLALA — bản Vite + React

Bản này chạy trực tiếp trên Windows, không sử dụng Cloudflare Workers hoặc Miniflare.

## Chạy trong VS Code

```powershell
npm install
npm run dev
```

Mở địa chỉ được hiển thị trong Terminal, thường là `http://localhost:5173/`.

## Tạo bản production

```powershell
npm run build
```

Thư mục kết quả là `dist`.
